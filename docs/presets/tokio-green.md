# Tokyo Green Preset

This preset is inspired by [tokyo-night-preset].

![Screenshot of Tokyo Green preset](/presets/img/Tokio_Green.png)

### Prerequisites

- A [Nerd Font](https://www.nerdfonts.com/) installed and enabled in your terminal

### Configuration

```sh
starship preset tokyo-green -o ~/.config/starship.toml
```
